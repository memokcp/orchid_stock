ตั้งค่า Google Apps Script

เชื่อมต่อกับ Google Sheets เพื่อบันทึกข้อมูลบน cloud

1. สร้าง Google Sheets ใหม่
2. ไปที่ Extensions → Apps Script
3. วางโค้ดจากไฟล์ Code.gs แล้ว Save
4. กด Deploy → New deployment → Web App
   Execute as: Me | Access: Anyone
5. Copy URL มาวางด้านล่าง
URL จาก Deploy → Manage deployments → Web App URL
❌ เชื่อมต่อไม่ได้ กรุณาตรวจสอบ URL
ใช้งานโดยไม่บันทึก
